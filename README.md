# CG-Depth

This repository currently provides an **early debugging version** of CG-Depth, including the complete training, validation, and inference code. Since it is directly derived from our research and debugging environment, the current version still contains some redundant, experimental, and temporary code. A cleaner and more organized release with redundant components removed and the project structure simplified will be provided in a future update.
